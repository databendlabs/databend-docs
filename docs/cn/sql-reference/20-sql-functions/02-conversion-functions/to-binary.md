将支持的数据类型（包括字符串、变体、位图、几何和地理）转换为其二进制表示形式（十六进制格式）。

另请参阅: [TRY_TO_BINARY](try-to-binary.md)

## 语法

```sql
TO_BINARY( <expr> )
```

## 显式指定格式的 String 输入

<FunctionDescription description="Introduced or updated: v1.2.964-nightly"/>

```sql
TO_BINARY( <string_expr>, '<format>' )
```

两参数形式支持以下格式：

- `hex`：将十六进制文本解码为字节。
- `base64`：将 Base64 文本解码为字节。
- 字符集标签，如 `utf-8`、`gbk` 或 `gb18030`：将 String 编码为该字符集的字节。编码限制见 [CONVERT_TO](convert-to.md)。

格式必须是标量常量，不能是列。标签不区分大小写。输入或标量格式为 `NULL` 时返回 `NULL`。输入无效、标签不受支持或目标字符集无法表示某个字符时会报错。不支持 UTF-16 编码。使用 [TRY_TO_BINARY](try-to-binary.md) 可在转换失败时返回 `NULL`。

显式格式不使用 `binary_input_format`。现有单参数形式对 String 输入仍使用该设置。Binary 结果存储字节，其显示文本取决于 `binary_output_format`。使用 [TO_HEX](to-hex.md) 查看字节：

```sql
SELECT TO_HEX(TO_BINARY('你好', 'gbk'));
-- c4e3bac3
```

## 示例

此示例将字符串转换为二进制：

```sql
SELECT TO_BINARY('Databend');

┌───────────────────────┐
│ to_binary('Databend') │
├───────────────────────┤
│ 4461746162656E64      │
└───────────────────────┘
```

此示例将JSON数据转换为二进制：

```sql
SELECT TO_BINARY(PARSE_JSON('{"key":"value", "number":123}')) AS binary_variant;

┌──────────────────────────────────────────────────────────────────────────┐
│                              binary_variant                              │
├──────────────────────────────────────────────────────────────────────────┤
│ 40000002100000031000000610000005200000026B65796E756D62657276616C7565507B │
└──────────────────────────────────────────────────────────────────────────┘
```

此示例将位图数据转换为二进制：

```sql
SELECT TO_BINARY(TO_BITMAP('10,20,30')) AS binary_bitmap;

┌──────────────────────────────────────────────────────────────────────┐
│                             binary_bitmap                            │
├──────────────────────────────────────────────────────────────────────┤
│ 0100000000000000000000003A3000000100000000000200100000000A0014001E00 │
└──────────────────────────────────────────────────────────────────────┘
```

此示例将几何数据（WKT格式）转换为二进制：

```sql
SELECT TO_BINARY(ST_GEOMETRYFROMWKT('SRID=4326;POINT(1.0 2.0)')) AS binary_geometry;

┌────────────────────────────────────────────────────┐
│                   binary_geometry                  │
├────────────────────────────────────────────────────┤
│ 0101000020E6100000000000000000F03F0000000000000040 │
└────────────────────────────────────────────────────┘
```

此示例将地理数据（EWKT格式）转换为二进制：

```sql
SELECT TO_BINARY(ST_GEOGRAPHYFROMEWKT('SRID=4326;POINT(-122.35 37.55)')) AS binary_geography;

┌────────────────────────────────────────────────────┐
│                  binary_geography                  │
├────────────────────────────────────────────────────┤
│ 0101000020E61000006666666666965EC06666666666C64240 │
└────────────────────────────────────────────────────┘
```
