Cloud Agent 是内嵌在 Databend Cloud 控制台中的 AI 助手。用自然语言提问——关于你的数据、集群、账单，或想自动化的任务——Agent 会直接在控制台内完成：执行 SQL、渲染图表、管理资源、搭建数据管道等。

每一步都由你掌控：只读操作立即执行，任何会修改账户或数据的操作都会先弹确认框，而你的查询结果默认只保留在浏览器中，除非你主动选择分享。

## 打开 Cloud Agent

点击任意控制台页面**右下角**的 Cloud Agent 按钮，Agent 会以侧边栏形式打开：

![控制台右下角的 Cloud Agent 启动按钮](@site/static/img/documents/cloud-agent/cloud-agent-launcher.png)

- **上下文栏**：面板底部的集群（Warehouse）、数据库和角色是 Agent 的工作上下文。SQL 在选中的集群上以选中角色执行，Agent 能做的事不会超出你角色的权限。
- **Try an example**：常见任务的一键模板，点击后可编辑文案再发送。
- **Recent chats**：历史会话，可随时接着上次的进度继续。

![Cloud Agent 面板：示例模板、最近聊天与上下文栏](@site/static/img/documents/cloud-agent/cloud-agent-panel.png)

## Cloud Agent 能做什么

Cloud Agent 通过 20+ 个能力域、100+ 个具体工具覆盖控制台全流程。你无需挑选工具——描述需求即可，Agent 会自动加载对应能力。

### 查询与分析数据

| 能力       | 你可以做什么                                                                                    |
| ---------- | ----------------------------------------------------------------------------------------------- |
| SQL        | 探索库表结构、把自然语言转成 Databend SQL 并执行。只读语句立即执行；写操作和 DDL 会先弹确认框。 |
| 图表       | 把查询结果变成可视化——12 种图表类型，支持自动选型，全部在浏览器本地渲染。                       |
| 查询历史   | 按时间、用户、集群、状态或耗时检索历史 SQL，排查慢查询和失败查询，并跳转 Query Profile。        |
| 运行中 SQL | 实时查看集群上正在执行的查询，定位卡住或占用资源的语句。                                        |
| 数据血缘   | 探索表级血缘与依赖关系。                                                                        |
| 文件       | 针对上传的文件提问（CSV、Parquet、NDJSON 等），或用 COPY INTO 加载成表。                        |
| 示例数据   | 加载开箱即用的公开数据集（Books、COVID-19、Cell Towers）快速上手。                              |

### 管理资源

| 能力                | 你可以做什么                                                        |

| 任务与任务流        | 查看 Task/Flow 及执行历史、对比版本，安全地执行、暂停、恢复或删除。 |

| 数据源   | 管理已保存的连接：MySQL、PostgreSQL、Kafka、AWS、TiDB、飞书等。                                          |

| 页面与时间感知 | 感知当前所在的控制台页面（操作成功后可刷新对应资源），并提供本地/UTC 时间以处理"今天""最近 7 天"类问题。 |

## Agent 可以执行哪些操作

Agent 的操作分为三个层级，让你始终清楚提出请求后会发生什么：

| 层级     | 示例                                                                                          | 行为                                                         |
| -------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 只读     | `SELECT`、`SHOW`、`DESCRIBE`、`EXPLAIN`；列出集群、任务、成员；查看账单或历史                 | 立即执行。                                                   |
| 修改类   | `INSERT`/`UPDATE`/`DELETE`、`CREATE`/`ALTER`/`DROP`，创建或删除集群、任务，邀请成员，提交工单 | 先弹出确认框，点击"运行"之前不会有任何变更。                 |
| 仅管理员 | 审计日志、集群配置变更、成员角色变更                                                          | 由角色权限把关。角色无权限时操作会被拒绝——点了确认框也不行。 |

:::note
Agent 始终在你自己角色的权限范围内工作。它能看到和做到的，不会超过你在控制台里能做的。
:::

## 使用图表

说一句"画个图"，Cloud Agent 会自动选择合适的图表类型，也可以直接指定：

- **对比**：柱状图、雷达图
- **趋势**：折线图
- **占比**：饼图、矩形树图、旭日图
- **相关性与分布**：散点图、热力图
- **指标与漏斗**：计分卡、漏斗图
- **金融与关系**：K 线图、关系图

图表全部在浏览器本地渲染（基于 ECharts）。配色、堆叠、排序、TopN、图例和标签都可以通过对话调整。单个图表上限为 2 万行 / 50 列 / 30 万单元格——数据更大时，Agent 会建议先用 SQL 聚合。

## 安全与隐私

Cloud Agent 的设计让你无需在安全与便利之间取舍：

- **数据不出浏览器。** 查询结果、账单明细、图表源数据都在本地处理，不会发送给 AI 模型。Agent 能看到的是你的 schema 和元数据——而不是单元格里的数据。
- **未经你确认不共享任何数据。** 只有你在结果上点击"分享给 AI"时，结果数据才会进入对话，且仅限有界的部分样本。
- **敏感列自动打码。** 共享有界样本（或 Agent 查看系统元数据）时，密码/令牌/密钥类列的值会被整体抹除，邮箱/手机号/卡号类列会被部分打码——一切发生在数据离开浏览器之前。
- **凭证不经过模型。** 连接密钥（数据库密码、访问密钥、Webhook 令牌）只在原生安全表单中录入，并从 Agent 可读的内容中抹除。
- **写操作必须确认。** 修改类操作在执行前都会弹出"运行/取消"对话框，确认后平台还会再次校验你的角色权限。
- **会话数据限定在你的账户内**，可随时从聊天历史中删除。

## 使用建议

- 像和同事沟通一样具体：能指名数据库、表或集群就尽量指名。
- 用追问逐步调整："改成堆叠柱状图""只看最近 7 天""加上美国地区"。
- 示例模板可以编辑：点击后修改文案再发送。
- 如果回复上方展示了结果表，那就是真实的查询输出——Agent 会做解读而不是复述。
- 用**新会话**开始全新对话；用**最近聊天**回到之前的工作。

:::note
Cloud Agent 目前处于 **Preview** 阶段，能力仍在持续演进。部分能力与平台相关：账单、工单和教程在 Databend Cloud 上提供，其他部署环境可能有所不同。
:::
